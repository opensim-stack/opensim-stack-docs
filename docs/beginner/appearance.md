# Beginner Appearance and Wearables

Use these IM prompts to manage outfits, clothing layers, and attachments.

## See what is currently worn

```text
What are you wearing right now?
```

```text
List your worn wearables and attachments.
```

## Wear an outfit folder

```text
Wear outfit folder 11111111-2222-3333-4444-555555555555 and replace what you are wearing.
```

```text
Add outfit folder 11111111-2222-3333-4444-555555555555 without replacing current items.
```

!!! tip "Replace vs add"
    "Replace" swaps existing outfit categories. "Add" keeps current items and layers in additional ones where possible.

## Save your current look

```text
Save your current outfit as Evening Demo Look.
```

```text
Save my current outfit snapshot under folder 11111111-2222-3333-4444-555555555555 named Stage Outfit v2.
```

## Wearables by item or type

```text
Wear wearable item 11111111-2222-3333-4444-555555555555 and replace same slot.
```

```text
Remove wearable item 11111111-2222-3333-4444-555555555555.
```

```text
Remove all Shirt layers.
```

## Attachments and attachment points

```text
Attach item 11111111-2222-3333-4444-555555555555 to RightHand.
```

```text
Move attachment item 11111111-2222-3333-4444-555555555555 to Spine and replace what is there.
```

```text
Detach item 11111111-2222-3333-4444-555555555555.
```

## Quick adjustment prompts

```text
Show transform for attached item 11111111-2222-3333-4444-555555555555.
```

```text
Set attached item 11111111-2222-3333-4444-555555555555 position to 0.0, 0.05, 0.02 and yaw to 15 degrees.
```

```text
Set attached item 11111111-2222-3333-4444-555555555555 scale to 1.1, 1.1, 1.1.
```

## Refresh appearance

```text
Refresh your appearance.
```

```text
Force rebake appearance.
```

## Shape slider edits

```text
List editable shape sliders with current values.
```

```text
Set visual param 33 to 0.65 and clamp to valid range.
```

```text
Set shape slider Nose Size to 0.4.
```

## Bake diagnostics

```text
Show appearance bake diagnostics.
```

```text
Run a bake cache probe with a 2.5 second timeout.
```

If responses look stale after changes, wait a moment and request the worn list again.

For full tool names and exact parameter behavior, see **Advanced Guide -> Appearance and Wearables**.
